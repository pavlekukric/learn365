# Cloud Design Prompt — History 365

I want to design a completely new app from scratch.

The app is called:

History 365 / Istorija 365

This is a premium daily learning app where users learn Serbian history through 365 short lessons.

Each lesson should take around 7–10 minutes to read.

The app must feel full premium, elegant, calm, and highly polished.

It should not look like:

- a generic SaaS dashboard
- a basic blog
- a cheap course website
- a childish gamified app
- a documentation site

The experience should feel like a premium learning platform, with navigation clarity similar to Pluralsight, but with a refined historical reading aesthetic.

## Core concept

- Home page introduces the app.
- User can enter the course `Istorija Srbije 365`.
- The course contains 365 lessons.
- Lessons are grouped into historical periods/chapters.
- Each chapter contains multiple lessons.
- The user can mark a lesson as completed.
- Completed lessons show a green circular checkmark.
- The active lesson is clearly highlighted.
- The app always shows total progress, for example `1 / 365 completed`.
- The app should include a historical timeline with years/periods.
- When a lesson is opened, the current year/period should be highlighted on that timeline.

## Main screens to design

### 1. Home page

The Home page should explain the app beautifully and clearly.

It should communicate:

- what the app does
- how the 365-day journey works
- why it is valuable
- that each lesson is short and easy to read
- that progress is tracked
- that the user can continue day by day

The Home page should feel premium, editorial, calm, and inviting.

It should have a clear CTA to start:

`Istorija Srbije 365`

### 2. Course overview page

When the user opens `Istorija Srbije 365`, show:

- course title
- short course description
- total progress: `1 / 365 completed`
- percentage completed
- remaining lessons
- current lesson
- next lesson
- list of historical periods/chapters
- progress per chapter
- CTA to continue learning

### 3. Lesson reader page

Desktop layout should have:

- breadcrumbs at the top:
  `Home > Istorija Srbije 365 > Historical period > Lesson`
- left sidebar with the course outline
- collapsible chapters/periods
- lessons inside each chapter
- green circular checkmark for completed lessons
- active state for current lesson
- reading time per lesson
- day number per lesson
- main reading area
- previous lesson button
- next lesson button
- mark as completed button
- total course progress visible
- historical timeline visible

### 4. Mobile layout

Mobile should be reading-first.

Mobile should have:

- no clutter
- sidebar transformed into drawer or lesson panel
- progress visible
- simplified breadcrumbs
- easy access to lesson list
- clear completed and active states
- comfortable reading typography

## Visual direction

The app should feel:

- premium
- elegant
- calm
- historical
- warm but modern
- trustworthy
- refined
- focused

Possible visual elements:

- cream/parchment background
- refined serif typography for reading
- clean sans-serif for UI
- subtle borders
- elegant cards
- calm neutral colors
- one strong accent color
- green only for completion
- strong spacing
- high-quality hierarchy

Avoid:

- too many colors
- heavy gradients
- childish gamification
- generic dashboard cards
- cluttered sidebars
- low contrast
- weak active states

## Important product rule

The app should be simple in functionality but exceptional in design quality.

The first version is focused only on:

- learning experience
- course structure
- reading
- progress
- completion
- premium design

Do not design payment, subscriptions, or login for now.
