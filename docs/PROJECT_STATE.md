# Project State

## Current Baseline — 2026-09-30

This section is the single "what is true right now" snapshot of Istorija 365 / Istorija Srbije 365 web v1. **Treat it as the floor — UI/UX should not regress below this state without an explicit owner decision.** The newest phase entries follow it; Phases 0–16 are in [`docs/archive/PROJECT_STATE_PHASE_LOG.md`](./archive/PROJECT_STATE_PHASE_LOG.md). What to pick next is in [`HANDOFF.md`](../HANDOFF.md).

### App state

- **Live:** https://istorija365.com/ — self-hosted on the owner's Hetzner VPS behind a Cloudflare Tunnel, isolated from the Računi app on the same box (runbook: [`docs/DEPLOY.md`](./DEPLOY.md)). The only origin; the old Vercel project is deleted.
- **Branch model:** trunk-based; each unit ships as one squash-merged PR. A push to `main` deploys only after a green CI, and only the tip of `main` is ever rolled out.
- **Last shipped:** Phase 18 — the user-side review fixes (below). Before it Phase 17 — the 2026-09-30 review backlog (PRs #60–#65), and before that Phase 16 (`/pregled`, PR #57) and Phases 8–15 (accounts, delivery, CI gates, reading time, backend reliability, era rail, polish, reader frame) — see the archived log.
- **Brand:** **Istorija 365** (masthead wordmark + `I` monogram, footer, every tab title `… · Istorija 365`, `og:site_name`, favicon, share card). The course is *Istorija Srbije 365*. Routes stay `/course/…/lesson/…` (English segments; renaming needs redirects — not done).

### UI/UX baseline (do not regress)

- **Surfaces and routes:** Home `/`, course overview `/course/istorija-srbije-365`, lesson reader `/course/istorija-srbije-365/lesson/day-NNN`, About `/o-aplikaciji`, Privacy `/privatnost`, account pages `/prijava`, `/nalog`, owner-only `/pregled` (404 for everyone else), a 404 page (`Stranica nije pronađena`, no canonical, noindex).
- **TopBar:** sticky, translucent; brand (monogram only below 420 px) + `Početna` · `Kurs` · `O aplikaciji` + the labelled progress capsule (`role="status"`, `Pročitano N / 365`) + the account slot when accounts are on. `aria-current="page"` only on the page itself; inside a lesson `Kurs` carries `aria-current="true"`. ≤ 720 px: brand · Kurs · capsule. Secondary routes mark nothing active.
- **Home:** hero (`Istorija Srbije 365`, 91 px at 1440 / 56 px on phones, one line from 1100 px), contract line `365 lekcija · 1 dnevno · 5–7 minuta` (derived range), then — first visit only — the lede and `Počni kurs` → Day 1, and the `Kako funkcioniše` block. **A returning reader (≥ 1 completed) gets no hero lede and no hero CTA (Phase 18):** the hero is the title + contract line, and the recommended-lesson card right under it is the one action (above the fold on a 390 × 844 phone). Then the `Tvoj N. dan` anchor (N = the resume lesson's day) above the recommended-lesson card, and the 8-era rail (`eraShort` labels, floored band weights, container-query fallback; the full era name is every band's accessible name).
- **Returning readers on prerendered pages (Phase 17):** an inline pre-paint script (`lib/progress/prePaint.ts`) sets `<html data-progress="started">` when `localStorage` holds a completed lesson; `data-newcomer` blocks (`block`: how-it-works, the hero lede + CTA; `inline`: anchor, cards, the overview's start card) stay hidden until the components render from the store, then the mark is removed. A returning reader never sees the newcomer Home flash.
- **Course overview:** progress card (start state `Počni · DAN 001` + `Počni od Dana 1`; in progress: a ring counting lessons + one `Tvoj N. dan` row + `Nastavi`), optional `Sačuvane lekcije`, then 8 era cards — each an `h3 > button` disclosure (era eyebrow in a 92 px column, title, years, description, `Pokaži odeljke · N`) with a progress bar and one action link. All eras closed on a fresh state; the whole era → section → lesson tree is in the server HTML (closed panels `hidden`), so the page carries all 365 lesson links. Scroll position restored within a session.
- **Lesson reader:** persistent shell in the route's layout (outline, drawer, sticky context header survive previous / next; the open lesson's row is revealed by scrolling the list, never the page). Desktop frame capped at `--shell-max` (1440) and centred, gutter `clamp(40px, 5vw, 80px)`, 660 px measure. **Era names (Phase 18):** the full `title` only where the era is shown as itself (course overview era cards, the vertical era rail, accessible names); `eraShort` wherever a lesson points at its era — breadcrumb, lesson eyebrow, next-lesson card, Home card, `Sačuvane lekcije`, outline headings. Server-rendered `LessonReader` (breadcrumb `Putanja` on desktop, header with eyebrow `[eraShort ·] n min čitanja · date` at 0.04em tracking + bookmark toggle, body with dropcap, H2 with 48 px above / 24 px below, figures, `Izvori`, trust line) and three client islands (bookmark, completion footer, reading-progress hairline in the shell). **No era strip under the article** (Phase 13 D5, decided 2026-09-30) — on desktop the outline names the eras. Completion: `Označi kao pročitano` → `Pročitano`, first-win line, next-lesson card, previous link, then the sign-in ask — only under a *completed* lesson, ≥ 2 completions, accounts on, signed out, not dismissed, one lesson per browser session. A second skip link `Preskoči na tekst lekcije` (first in `<main>`) jumps past the outline to `#lesson-reader`.
- **Mobile reader:** one-row sticky context header (`Sadržaj` · `Dan nnn` · `Pročitano N / 365`); ≤ 720 px the lesson header spaces by its flex gap only (no default h1 / p margins — Phase 18), so the first sentence starts at ~50 % of an 844 px screen (was ~61 %). The drawer has its own close row (the button no longer floats over the scrolling list) and opens with the compact era rail above the outline, centred on the open lesson, and closes on any link (also the current row) and when the viewport grows past 1024 px. Sections the shell opened by itself close again when the lesson moves to another section; sections opened by hand stay.
- **Accessibility floor:** `lang="sr-Latn"`; `--faint` is decoration only; outline rows say `, pročitano` to assistive tech; Serbian labels everywhere (`Putanja`, `N % pročitano`); focus is moved on account delete / cancel; error lines are red, not green. axe (serious / critical) runs on Home, course, a lesson, About, Privacy and the 404 in CI with no known exceptions.
- **Copy:** one vocabulary (*pročitano*, *počni*, *nastavi*), one day formatter (`@learn365/core` `format/day.ts`), ti-form, no gendered past tense. About speaks impersonally (one person runs the site; the texts were prepared with an AI model and are edited by that person). Privacy names what is stored (incl. account / session / per-lesson timestamps), the legal basis (consent for the account, legitimate interest for statistics and delivery), transfers (Google, Cloudflare — US), backups (at most 14 days), rights and the Poverenik; the controller is still "privatno lice" (owner to name).
- **SEO:** canonical on every public page, sitemap (course + 365 lessons), robots, JSON-LD (`Course` + `Organization` on the overview; `Article` / `LearningResource` + `BreadcrumbList` on lessons), meta descriptions cut at a word boundary ≤ 155 chars, one share card.
- **Visual direction:** Editorial only — Spectral + Inter + JetBrains Mono, warm OKLCH palette, hairlines. **Cascade rule (Phase 17):** `app/layout.tsx` imports `globals.css` before any component, so a CSS-module rule beats the global type classes (`.display`, `.h3`, `.tiny`, `.mono`, `.eyebrow`) on the same element — do not move that import.

### Technical baseline

- **Stack:** pnpm + Turborepo, Next.js 15 App Router, strict TypeScript, CSS Modules + token CSS variables, Zustand + persist, Vitest + Playwright. Packages: `apps/web`, `packages/{ui, ui-web, core, content}`, `tooling/`.
- **Fonts (Phase 17):** self-hosted with `next/font/local` — the same woff2 files Google served (`apps/web/lib/fonts/files/`, OFL licences beside them), two calls per family (`latin`, `latin-ext`) with the same family names and unicode ranges; Spectral italic 300 dropped. No build touches the network for fonts any more. (Local Windows builds never emit font preloads — a Next path bug; Linux CI / Docker do.)
- **Delivery:** 127–145 kB gzip client JS per route, counted as the whole layout chain + page (`scripts/bundle-size.mjs`, budget 175 kB / route, 300 kB raw / chunk, in CI). 373 prerendered routes; account pages and `/api/**` dynamic. Cloudflare caches `/_next/static` only.
- **Accounts + sync:** Google sign-in (code + PKCE), `__Host-l365_session` on https — the un-prefixed name is never read there (Phase 17), plain `l365_session` only on local http; Postgres 17 via Drizzle (PGlite on the laptop and in tests); union once per browser, server authoritative after, a marker for another user takes the replace path, implicit sign-out clears local stores. `/api/**` answers 503 on a database outage. Accounts are off unless all four env values are set; the default e2e suite runs that way.
- **Health + migrations (Phase 17):** `/api/health` → `{ ok, auth, db, migrations: off | pending | ok | failed }`, 503 unless the database is reachable and migrated. Start-up migrations retry forever while the database is unreachable (15 s → 30 s → 60 s cap); a failing migration still fails. Docker healthcheck `GET /` every 15 s (start period 45 s).
- **Deploy:** `deploy.yml` — image on green CI (`workflow_run`, the validated SHA), rollout only when that SHA is still the tip of `main`; `workflow_dispatch` only on `main`. `deploy.sh` (on the box — see HANDOFF for the pending copy) waits up to 150 s for `healthy`, then up to 120 s for `migrations: ok`, and rolls back to the previous tag otherwise. `backup.sh` keeps the 14 newest verified dumps and can copy off-box when `BACKUP_OFFBOX_TARGET` is set (DEPLOY §10). The deploy key's `authorized_keys` line should start `restrict,command="/srv/learn365/ssh-command.sh"` (DEPLOY §13a — owner step).
- **Security headers:** CSP (`'self'`, inline scripts/styles, Google avatars, `static.cloudflareinsights.com` for the visit statistics), HSTS, nosniff, Referrer-Policy, frame-ancestors none, Permissions-Policy; `x-powered-by` off.
- **Gates (CI on every PR and push to `main`):** gen-content drift check, validate-content, lint (`apps/web` and `packages/ui-web` both run the rules of hooks + jsx-a11y), typecheck (incl. `e2e/`), Vitest, build, bundle budget; a parallel e2e job runs Playwright `chromium-desktop`, `chromium-mobile`, `a11y-desktop`, `a11y-mobile` (axe) and `accounts-chromium` (a second server with accounts on over a throwaway PGlite — sign-in union / sign-out, `/nalog` delete, `/pregled` gating). A nightly workflow runs Firefox + WebKit (not a gate). 11 spec files.
